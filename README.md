# script-hub

A script hub GUI for Roblox executors: editor with syntax highlighting, saved scripts library,
ScriptBlox browser, live output log, settings, and per-account saves. Works on PC and phones.

## Run it

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Jakedapro/script-hub/main/gui.lua"))()
```

Running it again replaces the open copy.

## Files

- `gui.lua` — the whole GUI in one file (generated; don't edit by hand)
- `build/` — the generator and Studio test tools; see [build/README.md](build/README.md) to rebuild
